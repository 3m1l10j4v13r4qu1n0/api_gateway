# Reglas APA para Proyectos de Software

## Uso de Código
- Código en texto: Usar fuente monoespaciada
- Bloques de código: Sangría de 1.27cm
- Listados largos: Incluir como Apéndice

## Diagramas y Figuras
- Diagramas de arquitectura: Figura con título descriptivo
- Flujos de trabajo: Figura con leyenda explicativa
- Capturas de pantalla: Figura con nota de atribución si es necesario

## Tablas de Datos
- Tabla de comparación de tecnologías: Encabezados claros
- Tabla de requisitos: Formato consistente, numeración secuencial
- Tabla de resultados de pruebas: Datos presentados claramente

## Referencias Técnicas
- Documentación de APIs: Citar versión y fecha de acceso
- Repositorios de código: Incluir hash o versión específica
- Herramientas de desarrollo: Citar versión y autor/organización

## Checklist de Documentación
- Portada con título descriptivo
- Resumen de 150-250 palabras
- Estructura jerárquica de títulos
- Formato APA aplicado
- Código con fuente monoespaciada
- Figuras y tablas numeradas y tituladas
- Citas con sistema autor-año
- Referencias bibliográficas completas
- Apéndices para material complementario
